# Western Academic Assistant — downloads

This repository only hosts the Windows installer for the Western Academic Assistant desktop app.

**Download:** [western-assistant-setup.exe](https://github.com/ryan207m-design/western-academic-assistant-releases/releases/latest/download/western-assistant-setup.exe)

1. Run the installer. If Windows shows "Windows protected your PC", click **More info** → **Run anyway**.
2. Go back to the website's **Connect** page and click **Connect Brightspace**.
3. Sign in with your Western account in the window that opens.

Your Western password and Duo approval stay on your computer.
